# 外部数据微服务能力库技能规范 (Skill: External API Toolset Specification)

本规范为服务端挂载的标准化外部数据微服务能力清单（Tool Reference Manual）。
系统中当前部署有 11 个独立的微服务数据源，各服务通过 x402 协议提供数据查询（统一单价 0.001 USDC on Base Sepolia）。

---

## 1. 可用微服务数据源清单 (11 项能力定义)

### [服务 1] 近场地震与断裂带活动监测
- **服务 ID**: `earthquake`
- **专业领域**: 地质监测 (`geology`)
- **端点路径**: `/api/survival/earthquake`
- **定价规格**: 0.001 USDC
- **参数需求**: 需要目标地理坐标 (`lat`, `lon`)
- **数据源与能力**: 基于 USGS FDSN Event API，监测目标半径 500km 内过去 7 天 M2.5+ 地震烈度、震源深度及断裂带地壳活动。

### [服务 2] 极端气象与温风雨雪监测
- **服务 ID**: `storm`
- **专业领域**: 气象学 (`meteorology`)
- **端点路径**: `/api/survival/storm`
- **定价规格**: 0.001 USDC
- **参数需求**: 需要目标地理坐标 (`lat`, `lon`)
- **数据源与能力**: 基于 Open-Meteo 高清数值预报，提供实况风速、极大阵风、雨雪累计、最低气温及体感失温危险指数。

### [服务 3] 流域水文与洪涝漫滩预测
- **服务 ID**: `flood`
- **专业领域**: 水文学 (`hydrology`)
- **端点路径**: `/api/survival/flood`
- **定价规格**: 0.001 USDC
- **参数需求**: 需要目标地理坐标 (`lat`, `lon`)
- **数据源与能力**: 基于 Open-Meteo GloFAS 全球水文洪水预测系统，提供未来 7 天河道径流比率、洪峰到达日与低洼漫滩演进趋势。

### [服务 4] 数字高程与地形坡度勘测
- **服务 ID**: `terrain`
- **专业领域**: 地形测绘 (`topography`)
- **端点路径**: `/api/survival/terrain`
- **定价规格**: 0.001 USDC
- **参数需求**: 需要目标地理坐标 (`lat`, `lon`)
- **数据源与能力**: 基于 Copernicus DEM 90m 高程模型，采样十字邻点计算地表绝对海拔、局部最大坡度与地貌起伏。

### [服务 5] 大气沙尘与颗粒物浓度监测
- **服务 ID**: `dust`
- **专业领域**: 大气环境 (`air_quality`)
- **端点路径**: `/api/survival/dust`
- **定价规格**: 0.001 USDC
- **参数需求**: 需要目标地理坐标 (`lat`, `lon`)
- **数据源与能力**: 基于 Open-Meteo Air Quality，监测大气沙尘颗粒物浓度、PM10/PM2.5 质量浓度与地表光学厚度。

### [服务 6] 天文日照与晨昏蒙影窗口
- **服务 ID**: `sunlight`
- **专业领域**: 天文观测 (`astronomy`)
- **端点路径**: `/api/survival/sunlight`
- **定价规格**: 0.001 USDC
- **参数需求**: 需要目标地理坐标 (`lat`, `lon`)
- **数据源与能力**: 基于 Sunrise-Sunset API，计算目标点日出日落时刻、民用晨昏蒙影（微光）时间段与白天有效自然光照窗口。

### [服务 7] 空间天气与地磁暴监测
- **服务 ID**: `geomagnetic`
- **专业领域**: 空间天气 (`space_weather`)
- **端点路径**: `/api/survival/geomagnetic`
- **定价规格**: 0.001 USDC
- **参数需求**: 全局数据，无需经纬度
- **数据源与能力**: 基于 NOAA SWPC 全球行星 K 指数，提供实时地磁指数及 G1~G5 级地磁暴对无线电通信与卫星定位信号影响。

### [服务 8] 国际外汇法定货币汇率牌价
- **服务 ID**: `forex`
- **专业领域**: 国际金融 (`foreign_exchange`)
- **端点路径**: `/api/noise/forex`
- **定价规格**: 0.001 USDC
- **参数需求**: 全局数据，无需经纬度
- **数据源与能力**: 基于 Frankfurter 汇率数据，提供美元兑主要法定货币（CNY/EUR/JPY/GBP）实时外汇中间牌价与兑换结算比率。

### [服务 9] 猫科动物科普与生物事实
- **服务 ID**: `catfact`
- **专业领域**: 动物学科普 (`feline_zoology`)
- **端点路径**: `/api/noise/catfact`
- **定价规格**: 0.001 USDC
- **参数需求**: 全局数据，无需经纬度
- **数据源与能力**: 基于 Cat Facts Ninja API，提供猫科动物的生物学解剖特征、生活生理习性与驯化历史科学知识。

### [服务 10] 加密数字货币行情走势
- **服务 ID**: `crypto`
- **专业领域**: 数字资产 (`cryptocurrency`)
- **端点路径**: `/api/noise/crypto`
- **定价规格**: 0.001 USDC
- **参数需求**: 全局数据，无需经纬度
- **数据源与能力**: 基于 CoinGecko API，提供主流加密数字资产（如 BTC、ETH）在公开交易所的实时现货交易均价与 24 小时涨跌幅。

### [服务 11] 国际空间站轨道天顶轨迹
- **服务 ID**: `iss`
- **专业领域**: 轨道航天 (`orbital_tracking`)
- **端点路径**: `/api/noise/iss`
- **定价规格**: 0.001 USDC
- **参数需求**: 全局数据，无需经纬度
- **数据源与能力**: 基于 WhereTheISS.at API，提供国际空间站 (ISS) 实时星下点地表经纬度、近地轨道高度 (~420km) 与运行飞行速度 (~27,600 km/h)。

## 2. 参谋智能体决策评估原则 (Evaluation Principles)

智能决策参谋（AI Agent）在接收到特定任务委托时，必须基于以下方法论准则进行严谨推演，严禁预设立场或主观臆断：

1. **任务强因果关联原则**：
   - 全面审视具体任务的任务名称、行动目标、环境类型与执行要求；
   - 逐一分析各微服务的数据能力与当前任务是否存在真实、直接的应用因果关系。只有具备实质支撑价值的服务方可批准调用。
2. **链上微支付预算控制原则**：
   - 遵循 x402 协议经济学约束，杜绝无差别调用全部接口；
   - 严格排除与当前任务无关、冗余或缺乏决策影响的数据服务，将预算控制在必要范围内，并清晰记录排除每项服务的具体逻辑依据。
3. **数据求真与零假设原则 (Data Integrity)**：
   - 严禁对未获取到的环境数据进行凭空臆造或脑补；
   - 在后续研判中，只能基于实际采集成功的有效数据开展态势评估。若关键数据缺失，必须如实将其标记为情报盲区，并审慎考虑盲区对整体行动安全带来的不确定性风险。
